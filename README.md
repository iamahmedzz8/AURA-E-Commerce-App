# 🛍️ AURA — E-Commerce Mobile App

AURA is a modern Flutter e-commerce mobile application designed to deliver a smooth, intuitive, and visually appealing online shopping experience.

The project combines a carefully crafted UI/UX design with a scalable application architecture, state management, and REST API integration.

> **Project Status:** 🚧 In Development

## ✨ Project Overview

AURA aims to provide a complete shopping experience, from discovering products and browsing categories to managing a cart, exploring product reviews, and personalizing account settings.

The application is being developed using Flutter, following the MVVM architectural pattern and Cubit-based state management.

## 🎨 UI/UX Design

The design process uses AI-assisted design tools to accelerate prototyping and improve consistency across screens.

- **Design tools:** Figma and Google Stitch
- **Design direction:** Modern, clean, and user-friendly
- **Design goals:** Consistent components, intuitive navigation, responsive layouts, and light/dark mode support

**Figma Design:** [https://www.figma.com/design/SG7POXWtQ8GXq9TTfMqsw5/E-Commerce-Mobile-App?node-id=0-1&t=hRzVYI4y1d0JeMXv-1]

## 🏗️ Architecture

The project follows the **MVVM (Model–View–ViewModel)** architectural pattern, with Cubit managing presentation state.

The codebase will be organized into clear, maintainable modules to support separation of concerns, reusable components, and easier testing.

The final folder structure will be documented as implementation progresses.

## ⚙️ Getting Started

Once the Flutter source code is available, follow these steps:

1. Install Flutter and configure your development environment.
2. Clone the repository.
3. Navigate to the Flutter project directory.
4. Install dependencies.
5. Run the application on an emulator or physical device.

```bash
git clone https://github.com/iamahmedzz8/AURA-E-Commerce-App.git
cd AURA-E-Commerce-App
```

*Dependency installation and run commands will be added when the Flutter project structure is committed.*
